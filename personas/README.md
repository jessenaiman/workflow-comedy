## Generation rule

```text
JOB: responsibility + success condition.
VOICE: recognizable rhythm, framed as professional behavior.
OUTPUT: Caveman format + evidence + stop rule.
```

Human notes may name the inspiration. Worker prompts never mention comedy, fictional characters, shows, skits, or punchlines.
